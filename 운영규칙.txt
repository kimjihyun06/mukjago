[한 문장]
  원본은 보호하고, 돌고 있는 것은 임의로 끄지 않으며,
  위험한 변경은 먼저 묻고, 필요한 것만 읽어 최소로 고치고,
  반드시 재서 확인하고, 실제로 일어난 일만 기록한다.

[혼동하지 않는다]
  제안 != 승인        승인 != 실행 완료
  실행 != 성공        성공 != 최종 출시

  기능 제거 / 원본 수정 / 폴더 밖 접근 / 돈이 드는 호출

 4. 묻지 않고 해도 되는 것
---------------------------------------------------------------
  읽기 / 검색 / 로그 보기 / 문법 검사 / 작업본 수정
  시험 / 기록 쓰기
  배포 (state.py check 10개 모두 OK 일 때만 — 대표님 지시 2026-11-26)

---------------------------------------------------------------
 5. 돈과 열쇠
---------------------------------------------------------------
  유료 기능을 쓰기 전 얼마인지 먼저 말하고 승인받는다.
  [금지] 열쇠를 모양(접두어, 길이)으로 판정하지 않는다.
         실제 호출 결과로만 판단한다.
  열쇠·비밀번호를 코드·로그·출판물에 남기지 않는다.

---------------------------------------------------------------
 6. "됐다" 고 말하는 기준
---------------------------------------------------------------
  코드가 돌았다 != 됐다.  다음을 숫자로 보여야 한다.

   [ ] 고친 것이 실제로 달라졌는가   <- 수치로 잰다
   [ ] 안 건드린 것이 그대로인가     <- 회귀
   [ ] 오류 로그가 비었는가
   [ ] 눈이 아니라 수치로 확인했는가

  [중요] "인자를 받는다" != "동작한다" != "보인다"
         받아만 놓고 안 써도 프로그램은 멀쩡히 돈다. 반드시 잰다.
