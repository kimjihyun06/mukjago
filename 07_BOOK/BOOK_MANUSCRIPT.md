## 보기 - 원자료와 출판본의 차이

**원자료**

```
[USER] 사용자 지시
이것 좀 고쳐 줘.

[ERROR]
값만 받고 쓰지 않았다
```

**출판본**

```
사용자는 결과물을 보고 기능이 동작하지 않는다고 지적하였다.
확인해 보니 프로그램은 설정값을 받아들이기만 하고
실제로 사용하는 과정이 빠져 있었다. 오류는 발생하지 않았기 때문에
눈으로는 알아챌 수 없었다.
```

> **사실은 보존하되, 대화의 되풀이는 덜어 낸다.**
